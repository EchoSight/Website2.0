Services

Static detector analysis

End-to-end processing of full nights of acoustic data into QA’d call lists and activity summaries.

  • Includes: file ingestion, auto-triage + ecologist review, species/activity summaries
  • Deliverables: spreadsheets + GIS layers; optional figures for reports

Video & thermal review

High-volume footage processing with time-stamped annotations and shareable evidence reels.

  • Includes: behaviour tagging, event windows, evidence clips
  • Deliverables: annotated media, logs, summary tables
See package details

GIS mapping & deliverables

Publication-ready maps and spatial datasets for planning and stakeholder briefings.

  • Includes: symbology, layouts, web map (optional)
  • Deliverables: GeoPackage/shapefiles, PDFs/PNG figures
See package details

Desktop review (desk study)

Rapid constraints screening using third-party datasets and imagery to de-risk surveys and focus effort.

  • Includes: LERC data request coordination, NBN Atlas & MAGIC queries, designations, aerial imagery & LiDAR checks
  • Deliverables: constraints summary, source citations, GIS layers & overview maps

Survey data onboarding

Rapid intake of detector, video and field records with naming conventions and metadata applied from day one.

  • Includes: folder structure, templates, QC checks
  • Deliverables: ready-to-process data room + intake report

BTO & statutory submissions

Validation and export workflows that slot straight into BTO and planning portal pipelines.

  • Includes: schema validation, export formats, upload support
  • Deliverables: compliant files + submission log

Data governance & reporting packs

Version-controlled workflows, GDPR-compliant data rooms and dashboards that track sign-off to completion.

  • Includes: peer-review checklists, access controls, progress dashboard
  • Deliverables: report-ready tables/figures + audit trail
